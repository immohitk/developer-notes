## ✅ Best Practices

- Use semantic HTML tags whenever possible (for example, `<header>`, `<main>`, `<section>`, and `<footer>`).
- Always close tags that require a closing tag.
- Write tag names in lowercase for consistency and readability.
- Properly nest HTML tags to maintain a valid document structure.
- Use indentation to make your HTML code clean and easy to understand.
- Avoid using deprecated HTML tags in modern web development.
